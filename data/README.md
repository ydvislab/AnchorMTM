# Raw data

Raw data are not in this repository. They are needed only to regenerate the bundled results (Level 2 in the main
README); every figure and table can be rebuilt without them. Put them under `data/` (or point `ANCHORMTM_DATA` at
another folder) with the layout below. The experiments record the SHA-256 of every input they read.

| Sequence | Used by | Source | Expected location |
|---|---|---|---|
| Ring (40 frames) | planar pipeline | generated by `experiments/ring` from the archived generator of the original authors (`experiments/ring/source`); no download | — |
| Wildfires (32 frames) | planar pipeline, order-model experiments | `wildfire.json`, Zenodo record 11234747 (`https://zenodo.org/records/11234747/files/wildfire.json`), SHA-256 `2a8dd31bf6d222d7de673c7e7b2af94550660f1996b0a5db256d97f2b9c2ed9f` | `data/real/wildfire/wildfire.json` |
| Storms, hourly (744 frames, Dec 1999) | planar pipeline | ERA5 hourly mean sea level pressure (Copernicus Climate Data Store, *ERA5 hourly data on single levels*), 30-75 N, 30 W-40 E, 0.25°, 17 Nov 1999 - 14 Jan 2000 (December 1999 is used; the margins feed the 192-hour moving mean), netCDF with `msl`, `valid_time`, `latitude`, `longitude`; SHA-256 of the file used: `205584959947bdda8252187d7dc5f2dee8f85b4ffa0a62ee3dde65fa3e498677` | `data/real/ERA5_MSLP/ERA5_MSLP_19991117_20000114.nc` |
| Storms, 12-hourly | order-model experiments (`experiments/era5.py`) | public ARCO-ERA5 mirror: `python analysis/era5_arco.py` and `python analysis/era5_arco_expanded.py 1999-11-17T00 2000-01-15T00 data/real/ERA5_MSLP/ERA5_MSLP_19991117_20000114_12h_arco_expanded.nc` (needs the `era5` extra) | `data/real/ERA5_MSLP/` |
| OLR | order-model experiments | NOAA interpolated OLR, daily (`olr_cdr_day/olr.day.mean.v2.nc`): `python tools/fetch_public_scalar.py olr` | `data/public_scalar/` |
| PM2.5, daily 2000 | order-model experiments | CN-Reanalysis, DOI 10.57760/sciencedb.35623 (manual download), then `python tools/prepare_cn_pm25.py` | `data/public_scalar/` |
| PM2.5, hourly Jan 2017 (case study) | Table 1, Fig. S7 | ChinaVis 2021 CAQRA hourly archive, northern China 110-120 E, 32-41 N | bundled as `results/pm25_hourly/`; the generating scripts are not part of this repository |
| Tangaroa (201 volumes) | volume experiments | velocity volumes from the FAU visual computing datasets page (`https://www.vc.tf.fau.de/publications/datasets/`): `PYTHONPATH=src:. python -m experiments.volume3d.prepare_tangaroa_paper` (see `experiments/volume3d/README.md`) | `data/real/Tangaroa-FAU/` |
| Cylinder (102 volumes) | volume experiments | 3-D square cylinder flow (`https://www.csc.kth.se/~weinkauf/datasets/SquareCylinder.7z`): `PYTHONPATH=src:. python -m experiments.paper1_suite.prepare_3d` (see `experiments/paper1_suite/README.md`) | `data/real/paper1_suite/square-cylinder3d/` |

The hourly Storms subset can also be read from the ARCO mirror (change the 12-hour step in `analysis/era5_arco.py`), but
that file is not byte-identical to the CDS download whose hash is recorded in `results/planar_pvis2027/Storms/protocol.json`.
